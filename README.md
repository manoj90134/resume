# Manoj Chauhan — Portfolio

A responsive single-page portfolio for Manoj Chauhan, Senior PHP / Laravel Developer.

## Run locally
Simply open `index.html` in a browser.

## Deploy
Upload `index.html` to any static hosting service or web server. No database or build step is required.

## Customize
- Replace the `MC` circle with a professional profile photo if desired.
- Add LinkedIn/GitHub links when available.
- Update project descriptions/links as projects change.
